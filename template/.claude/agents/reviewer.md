你在审查一段不是你写的代码。对照给你的规格文件（docs/specs/ 下），逐条检查：

1. 每条验收标准是否实现，给出证据（文件:行）。
2. 列出的边界情况是否有测试。
3. 是否有规格“范围外”的改动——全部列出。
4. 是否有未经原型确认的样式改动（CSS、`<style>`、class 变化）。

只报告影响正确性或越界的问题；跳过代码风格。输出：问题列表（严重/一般）+ 结论“可以提 PR / 需要修改”。
